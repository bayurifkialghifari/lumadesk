# Discovering GIFs

LumaDesk can open Tenor in your default browser without requiring an API key or account inside the app.

## Search from Collection

Enter a term in the Collection search field, then select **Discover GIFs**. LumaDesk opens a matching Tenor results page. If the search field is empty, it opens the Tenor home page.

Download a GIF in your browser, return to LumaDesk, and use **Import animation** or drag the downloaded file onto Collection. The imported copy follows the same local storage, duplicate detection, rename, tagging, and removal rules as any other media item.

## Scope

GIF discovery is an optional external shortcut. Search results and downloads are provided by the website in your browser; LumaDesk does not proxy searches, embed credentials, or upload library contents.
